 介護のレクプリ(塗り絵ギャラリー) 使い方
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【見る・印刷する】
  「index.html」をダブルクリックするとブラウザで開きます。
  ページは3つあり、上のタブで切り替えます。
  ・「脳トレを選ぶ」…脳トレ(ことわざ絵など)の一覧
  ・「塗り絵を選ぶ」…全部の一覧。「季節」「ジャンル」「難しさ」
    「使用状況」のプルダウンで絞り込みできます。
    (「✕ 絞り込みを解除」で全部リセット)
  ・「★ お気に入り」…お気に入りに入れたものだけの一覧
  各カードの「保存」で画像がダウンロードフォルダに保存されます。
  保存したら、ブラウザ右上の ↓ マーク →「フォルダに表示」で
  保存先が開くので、そこから印刷してください
  (画像を右クリック →「印刷」や、Windowsの写真アプリの印刷で
   A4を選べばきれいに収まります)。
  画像を押すと大きく表示されます(そこからも保存できます)。
  脳トレなど答えのあるものは1枚のカードにまとまっていて、
  カードの「答え」ボタンで答えを保存、拡大表示の
  「答えを見る」で答えを確認できます。
  新しく追加した塗り絵ほど上に表示されます。

【カレンダーについて】
  「塗り絵を選ぶ」ページの「📅 カレンダーはこちら」ボタンで、
  「2026年8月」「2026年9月」のような月の一覧が開き、
  月を押すとその月のカレンダーが表示されます。
  各月に「絵付き」と「貼り付け用(上が空白で、好きな塗り絵を
  貼れるタイプ)」があります。
  追加するときは管理ページで種類を「カレンダー」にして、
  お題を「10月カレンダー」のように付けると月順に並びます。

【お気に入りとまとめて保存】
  カード右上の「☆」を押すとお気に入りに登録できます(★になります)。
  「★ お気に入り」ページを開くと「まとめて保存」で
  お気に入り全部をいっぺんに保存できます。
  初回は「保存先のフォルダ」を聞かれるので、デスクトップなど
  好きな場所を選んでください。その中に「介護のレクプリ」という
  フォルダが自動で作られ、全部そこに保存されます。
  2回目からは同じ場所に自動で保存されます。
  ※ フォルダ選択の画面で「変更を保存」を聞かれたら押してください。
  ※ 初回は画像の読み取りのため、ギャラリーのフォルダ選択を
    追加でお願いされることがあります(その1回だけです)。

【使用記録について】
  保存をすると、その塗り絵に
  「💾 保存済 8/1」のような緑のバッジと日付が付きます。
  ・「使用状況」で「未使用」を選ぶと、未使用のものだけ表示できます
  ・まちがえて付いた記録は、緑のバッジを押すと消せます
  ※ 記録はそのパソコンのブラウザに保存されるため、
    別のPCで開くと記録は共有されません。

【新しい塗り絵を追加する】※管理ページで簡単にできます
  1. 「admin.html」をダブルクリックで開く
     (ギャラリー下部の「管理ページ」リンクからも開けます。
      Google Chrome か Microsoft Edge で開いてください)
     パスワードを聞かれます(最初は「1234」)。
  2. 「フォルダを選ぶ」で、このフォルダを選ぶ
     (「変更を保存しますか?」と出たら「変更を保存」を押す)
     2回目からは「↩ 前回のフォルダを使う」を押すだけでOKです
  3. 画像をドラッグ&ドロップして、お題・種類(塗り絵/脳トレ)・
     季節・ジャンル・難しさを選び、「保存する」を押すだけ
  ※ ファイル名が「ひまわり 初級.png」のようになっていると
    お題と難しさは自動で読み取られます
  ※ 「まとめて設定」を使うと全部に同じ季節などを一気に付けられます

【答えのある脳トレについて】
  管理ページで塗り絵と脳トレは切り替えボタンで分かれています。
  問題の行の「答えを設定」を押して答えの画像を選ぶと、
  同じカードに問題と答えがセットになります。
  (新規追加のときも「答えを設定」で一緒に登録できます)

【直したいとき・消したいとき】
  管理ページの「登録済みの一覧」で、お題・種類・季節・
  ジャンル(風物詩/風景などから選択)・難しさを書きかえて、
  その行の「更新」ボタンを押すと保存されます。
  ジャンルは「＋新しいジャンル…」を選ぶと自由に増やせます。
  消したいときは「削除」を押すだけです。
  ギャラリー側は右上の「🔄 更新」を押すとすぐ反映されます。

【管理ページのパスワードを変えるには】
  「admin.html」をメモ帳で開いて、上のほうにある
  const ADMIN_PASSWORD = "1234";
  の「1234」を書きかえて保存します。("" を空にすると画面なし)
  ※ 簡易的なカギです(詳しい人がファイルの中を見れば分かります)。
    職員以外がうっかり操作しないようにする用途のものです。

【手動で編集したいとき(上級者向け)】
  「data.js」をメモ帳で開いて行を追加・削除してもOKです。
  例: { season: "秋", genre: "食べ物", title: "ぶどう", diff: "初級", file: "budou.png" },
  ※ 季節は「春・夏・秋・冬・通年」/ 行末のカンマを忘れずに

【施設内で共有したいとき】
  この「nurie-gallery」フォルダごと共有フォルダや
  USBメモリにコピーすれば、どのPCでもそのまま使えます。
  (フォルダ名は文字化け防止のため半角英字にしています。
   分かりやすい日本語名に変えてもそのまま動きます)

【いずれネット公開したくなったら】
  このフォルダをそのまま無料ホスティング(GitHub Pagesや
  Netlifyなど)にアップすれば公開できる作りになっています。
  そのときはまたClaudeに相談してください。
