画像の差し替え

作品の絵だけを新しいものに入れ替えます | ← 管理ページ ｜ ギャラリー

1. 差し替える作品を選ぶ

選んだ作品のファイル名で書き出します。ファイル名が同じなので、GitHubに上げるとそのまま上書きされます。

2. 新しい画像を入れる

ここに画像をドラッグ、またはクリックして選ぶ
(PNG / JPG。作り直した線画をそのまま入れてください)

3. 書き出す

GitHubへの上げ方

  1. リポジトリで images フォルダを先に開く
  2. Add file → Upload files に、書き出した画像をドラッグ
  3. Commit changes を押す(同じ名前なので上書きされます)
  4. サイトを開いて Ctrl+F5。古い絵が残っていたらもう一度
data.js はさわる必要ありません。絵だけが入れ替わります。
